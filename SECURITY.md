# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of VidhyaPath seriously. If you believe you have found a security vulnerability in this project, please report it responsibly:

1. **Email:** Please send vulnerability reports directly to `yashpatadiya1724@gmail.com`.
2. **Details:** Include detailed reproduction steps, potential impact, and suggested fixes if available.
3. **Response:** You will receive an acknowledgment within 48 hours.
4. **Disclosure:** Please do not file public issues for sensitive security vulnerabilities until they have been resolved.
