# Contributing to VidhyaPath

Thank you for contributing to VidhyaPath. We welcome contributions that improve neurodivergent accessibility, expand curriculum quizzes, and enhance multi-sensory learning interfaces.

## Accessibility Guidelines
1. **WCAG Compliance**: All UI contributions must adhere to WCAG 2.1 AA contrast standards.
2. **Sensory Safety**: Never introduce flashing elements (>3 Hz) or disruptive autoplay audio.
3. **No Heavy Frameworks**: Keep the core student interface zero-dependency and lightweight so it executes flawlessly on entry-level tablets.
4. **Branching**: Submit changes from feature branches, never directly to `main`.
